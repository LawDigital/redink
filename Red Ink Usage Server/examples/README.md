# Configuration examples

These files are deployment fragments and fictional test vectors, not ready-to-use production settings.
Merge the relevant fragment into your existing configuration, preserving local sections, update rules and signatures.
Use the separate ingestion/configuration tokens printed by `init`; do not put tokens in query strings.

`addin_transport_vectors.json` contains constructed protocol examples accepted by the Python parser. It does not represent executed VB serialization or real users.
